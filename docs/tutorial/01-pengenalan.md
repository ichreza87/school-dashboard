# 01 - Pengenalan

School Dashboard adalah Sistem Informasi Manajemen Sekolah open-source untuk guru & operator. Dibuat dengan TypeScript, React, Prisma.

**Tujuan:** guru tanpa latar belakang pemrograman dapat mengelola siswa, kehadiran, nilai, dan laporan dengan UI sederhana.

**Stack:** Frontend Vite + React + Tailwind + Recharts, Backend Express + Prisma (SQLite lokal / Postgres server), Dapodik Provider abstraction.

**Mode:** Local (1 PC), LAN (operator sebagai server), Server (VPS).
