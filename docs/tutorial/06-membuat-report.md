# 06 - Membuat Report

Report Center di /laporan. Template Builder menyimpan kolom sebagai JSON di reportTemplates. Contoh R7: name,nip,nuptk,status,golongan,pendidikan,mapel,jam.

Buat template baru: isi nama + pilih entity + daftar kolom koma -> Simpan -> Export Excel (xlsx) atau Print (window.print). Kolom bisa di-reorder, rename, hide.
