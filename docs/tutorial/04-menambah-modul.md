# 04 - Menambah Modul

1. Tambah model di schema.prisma -> migrate.
2. Tambah route di backend/src/index.ts (ikut pola GET/POST /api/<modul> dengan authMiddleware).
3. Tambah page di frontend/src/pages/<Modul>.tsx, daftarkan di App.tsx.
4. Tambah link di components/Layout.tsx.
5. Tulis test di tests/.
