# Demo Guide

## Demo Data
1 sekolah, 100 siswa, 20 guru, 6 rombel, 10 mapel (`npx prisma db seed` di backend/prisma/seed.ts).

## Skenario Demo 5 Menit untuk Guru
1. Login admin/admin123
2. Dashboard: lihat total siswa 100, kehadiran 94.8%
3. Siswa: cari nama, buka profil (10 tab)
4. Kehadiran Siswa: pilih rombel 5A -> Tandai Semua Hadir -> Simpan
5. Nilai: pilih rombel 5A + Mapel MTK -> isi nilai -> Simpan
6. Laporan: Report Center -> Template R7 -> Export Excel
7. Dapodik: Test Connection -> Tarik Data -> Preview (NEW/UPDATED/CONFLICT) -> Sinkronisasi
