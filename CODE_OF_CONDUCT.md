# Code of Conduct

Kami berkomitmen menjaga lingkungan yang ramah dan inklusif untuk semua kontributor, termasuk guru, operator, dan developer.

- Bersikap hormat dan profesional.
- Tidak ada ujaran kebencian, diskriminasi, atau pelecehan.
- Kritik yang membangun, bukan menyerang pribadi.

Pelanggaran dapat dilaporkan via Issue atau email maintainer.
